🚀 SaveIQ — Smart Savings OS

SaveIQ is a modern personal finance dashboard designed to help users track savings goals, monitor transactions, understand financial progress, and receive AI-powered financial insights.

⚡ Getting Started

1. Clone the repository

git clone https://github.com/Prathmesh7117/SaveIQ.git

2. Open the project folder

cd SaveIQ

3. Install dependencies

npm install

4. Start the development server

npm run dev

5. Build for production

npm run build

⸻

🔑 Environment Variables

Create a .env file in the root directory for API credentials when required.

Example:

GEMINI_API_KEY=your_api_key_here

Security Note: Never upload real API keys or sensitive credentials to GitHub.

⸻

💾 Data Persistence

SaveIQ currently uses browser localStorage to persist savings missions and transaction data between sessions.

This allows users to retain their saved financial information when they revisit the application using the same browser storage.
